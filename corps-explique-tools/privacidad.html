Política de privacidad

Última actualización: 3 de noviembre de 2026.

Qué es

Corps Explique Tools es una herramienta interna que usan solo los dueños de los canales de YouTube Cuerpo Explicado y Corps Explique para gestionar sus propios canales. No tiene usuarios externos.

Qué datos de Google usa

Con el permiso de la cuenta dueña del canal, la herramienta usa los Servicios de la API de YouTube para:

  • subir videos propios y cambiar su miniatura, título, descripción e idioma;
  • leer los datos y las estadísticas de los propios canales (vistas, retención y suscriptores) con la API de YouTube Analytics.

Permisos que pide: youtube.upload, youtube y yt-analytics.readonly.

Dónde se guardan

El permiso de acceso y las estadísticas se guardan solo en el computador del dueño de los canales. No se suben a otros servidores.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros y no se usan para publicidad.

El uso y la transferencia de la información recibida de las API de Google cumple la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Servicios de YouTube

Esta herramienta usa los Servicios de la API de YouTube. Al usarla aceptas los Términos del Servicio de YouTube, y se aplica la Política de Privacidad de Google.

Cómo quitar el acceso

Puedes retirar el permiso cuando quieras en la página de permisos de tu cuenta de Google. Para borrar los datos guardados basta con eliminar los archivos de la herramienta en el computador.

Contacto

A través del canal de YouTube Cuerpo Explicado.

Privacy policy (English)

Corps Explique Tools is an internal tool used only by the owners of the YouTube channels Cuerpo Explicado and Corps Explique to manage their own channels. With the channel owner's permission it uses YouTube API Services to upload the owner's own videos, set their thumbnails, titles, descriptions and language, and read the owner's own channel analytics (scopes: youtube.upload, youtube, yt-analytics.readonly).

Access tokens and analytics are stored only on the owner's computer. They are never sold, shared with third parties or used for advertising. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

By using this tool you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. You can revoke access at any time at myaccount.google.com/permissions. Contact: via the YouTube channel Cuerpo Explicado.
